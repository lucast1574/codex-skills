# Motion graphics

Crear una composición con jerarquía visual, ritmo y propósito claros. Respetar assets, identidad y stack del proyecto. Inferir detalles reversibles; preguntar solo por información imprescindible como una referencia ausente o un formato de entrega incompatible.

Para animación en un sitio existente, usar su stack y convenciones. Para una pieza independiente, elegir entre un preview HTML/SVG/canvas y un pipeline de video según la entrega solicitada y las herramientas disponibles. No introducir un framework pesado para una animación simple.

Consultar [web.md](references/web.md) para animación interactiva o un preview web; [video.md](references/video.md) solo para exportar una pieza de video.

Usar generación de imágenes únicamente si hacen falta assets raster nuevos; la tipografía, geometría y animación se construyen en el formato nativo. No presentar un mockup estático como una animación terminada.

Revisar visualmente frames clave y la reproducción real cuando haya un preview accesible. Comprobar duración, dimensiones, legibilidad, entrada/salida y continuidad del loop cuando corresponda. Diferenciar un archivo generado de uno efectivamente reproducido y verificado. Entregar el archivo editable y el formato final solicitado; si la exportación está bloqueada, conservar la fuente y explicar exactamente qué falta.
